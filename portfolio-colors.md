# Portfolio Color Palette

Exact colors used in `portfolio.html`. Tailwind class names are shown so you can find them in the code.
Where a color is used with transparency, the opacity is noted.

---

## Light theme

| Role | Hex | Where it's used | Source |
|---|---|---|---|
| Page background | `#f6f1e7` | Page, menu overlay, theme-toggle button | custom CSS / `bg-[#f6f1e7]` |
| Main text | `#1c1917` | Body text | custom CSS |
| Ink (borders, buttons) | `#1c1917` | Card borders (80%), tile borders, outline buttons, primary button fill, project tags, active menu tile, footer border (80%) | `stone-900` |
| Accent red | `#b91c1c` | Japanese labels, heading underline, kanji, timeline line and dots, home "sun" circle, menu 門 button, "Things I Like" chips, Send button, menu tile hover fill, card hover shadow, input focus ring (40%) | `red-700` |
| Text on dark fills | `#ffffff` | Text on red and ink fills | `white` |
| Card fill | `#ffffff` @ 60% | Cards | `bg-white/60` |
| Input fill | `#ffffff` @ 70% | Contact form fields | `bg-white/70` |
| Divider lines | `#a8a29e` @ 40% | Lines inside the About facts card | `stone-400/40` |
| Paper-dot texture | `#786450` @ 18% | Background dot pattern, written as `rgba(120,100,80,.18)` | custom CSS |

## Dark theme

| Accent red (unchanged) | `#b91c1c` | Menu 門 button, chips, Send button, tile hover fill, card hover shadow | `red-700` |
